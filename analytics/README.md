# ULQF v0.4.0 — analytics deployment (staged)
- Collector.gs is source only. The Google Apps Script project and deployed endpoint are not provisioned by GitHub.
- Open private GLAIR, Extensions > Apps Script, paste Collector.gs into Code.gs, save, run setupULQF once as the workbook owner and authorize. Use Deploy > New deployment > Web app > Execute as me > Who has access: Anyone (if permitted). Copy the resulting /exec URL. GET must report configured:true; POST canary must create a test event. Never publish a sheet ID or credentials in this repository.
- In analytics/client.js set endpoint to the verified /exec URL only after owner authorization and successful collector test. Visit canary in a normal browser and verify one test row in ClickEvents; confirm test is excluded from ClickDaily.
- Production alias events require one matching ursua.cc alias registry row with status ISSUED, VERIFIED or ACTIVE. No user-controlled destination or timestamp. Best effort, no unique visitor tracking. Public anonymous POSTs can be forged; caps and recent-ID deduplication limit accidental abuse but do not authenticate humans. 5,000/day circuit breaker; Apps Script quotas may be lower. No IP address or full referrer URL is stored by collector. Google transport may process network metadata.
- If disabled, unavailable or blocked, redirect still proceeds. No cookies; respects DNT/GPC where browser reports them. Test both JS and no-JS fallback.
- Prior to production issuance reconcile legacy aliases, HTTPS and live resolution. No automatic claims of cross-chat connector availability.
