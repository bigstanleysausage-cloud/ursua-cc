# ULQF v0.5.0-A — analytics workbook separation
- Collector.gs is source only. The Google Apps Script project and deployed endpoint are not provisioned by GitHub.
- Historical initial setup only (already completed): open the original collector workbook, now ULAS, Extensions > Apps Script, paste Collector.gs into Code.gs, save, run setupULQF once as the workbook owner and authorize. Do NOT run setup or deploy in the new GLAIR master. No redeployment is required for the workbook rename. Use Deploy > New deployment > Web app > Execute as me > Who has access: Anyone (if permitted). Copy the resulting /exec URL. GET must report configured:true; POST canary must create a test event. Never publish a sheet ID or credentials in this repository.
- In analytics/client.js set endpoint to the verified /exec URL only after owner authorization and successful collector test. Visit canary in a normal browser and verify one test row in ClickEvents; confirm test is excluded from ClickDaily.
- Production alias events require one matching ursua.cc operational mirror row in ULAS Aliases with status ISSUED, VERIFIED or ACTIVE. No user-controlled destination or timestamp. Best effort, no unique visitor tracking. Public anonymous POSTs can be forged; caps and recent-ID deduplication limit accidental abuse but do not authenticate humans. 5,000/day circuit breaker; Apps Script quotas may be lower. No IP address or full referrer URL is stored by collector. Google transport may process network metadata.
- If disabled, unavailable or blocked, redirect still proceeds. No cookies; respects DNT/GPC where browser reports them. Test both JS and no-JS fallback.
- Prior to production issuance check current GLAIR reservations, GitHub paths, HTTPS and live resolution. Cloudflare recovery waived by ULQF-CS-20261126-001. No automatic claims of cross-chat connector availability.

- Private GLAIR master owns permanent records; ULAS holds analytics and the minimal active A:H alias mirror. Explicit authenticated mirror synchronization and readback required. No inbound collector writes to the master. Workbook separation does not add rate limits or isolate Google account privileges. Collector v0.5.0-B hardening deferred.
